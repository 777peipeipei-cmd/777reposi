## リーク（答えの混入）の確認
- 使ったのはレース前に分かる情報だけ。本番ST、本番進入、今節成績、得点率、レース後コメント、決まり手は使っていない。
- 全国勝率やモーター2連率は節ごとに値が変わり、同じ節の中では変わらない（例: 同じ選手で 3.16 → 3.36 → 3.87 → 4.04）。つまり「今の値」ではなく **当時の出走表の値**。リークの心配は小さい。

## 学んだこと
1. **1号艇がB級ならインを信用しない。** 1着率は3割弱で、平和島でも特に弱い。1号艇の1着固定はA1・A2のときだけにする。
2. **後半レース（11・12R）はA級の1号艇がほぼ逃げる。** 前半〜中盤（1〜8R）は1号艇の1着が3〜4割しかなく、荒れやすい。
3. **逃げた時の2着は2コースと3コースがほぼ同じ（約3割ずつ）。** 10/31 は2コースばかりに見えたが、1年分で見ると3コースも同じくらい来る。4コースは2割程度。
4. **展示タイム1位は効く。ただし内側の艇の場合だけ。** 展示1位の1号艇は5割を超える。外の艇は展示1位でも勝ちきれない（6コースは5%）。
5. **モデルを複雑にしても、1着予想はコースと級別でほぼ決まる。** ロジスティック回帰で効いていたのは、枠番・全国勝率・モーター3連率・直近勝率・展示タイムの差。
6. **3連単1点買いは、どの方法でも約15レースに1本しか当たらない。** 回収率を本気で上げるには、オッズ（人気）を特徴量に入れて、点数を絞るか広げるかを決める必要がある（今回はオッズは使っていない）。

## オッズ込みモデル（回収率狙い）
コード: `heiwajima/scrape_odds.py`（オッズ取得）、`heiwajima/ev_model.py`（モデル・買い方・評価）

**やり方**
1. 艇ごとの1着確率を勾配ブースティングで出し、Harville 式で3連単120通りの確率（モデル確率）にする。
2. **締切5分前**の3連単オッズから市場確率（1/オッズを正規化）を作る。最終オッズは締切後にしか分からないので、判断には使わない。払戻は実際の確定配当で計算。
3. Benter 型の合成：P ∝ exp(a·log モデル確率 + b·log 市場確率)。
4. 買い方：期待値（P × 5分前オッズ）または「モデル確率 ÷ 市場確率」が閾値以上の目を買う。オッズ上限と1レースの最大点数も決める。
5. 閾値などは **8〜9月（395R）の日付単位の交差検証だけ** で決めた。10月（181R）は最後に1回だけ評価し、調整はしていない。
6. 「オッズ由来の特徴量（市場の1着確率とその順位）を艇モデルに入れる版」も試した。

**合成の重み**: モデル a≈0.03、市場 b≈1.06（オッズ特徴量入りの版は a≈0、b≈1.1）
→ **モデルは、オッズに含まれている以上の情報をほとんど持っていない**。

**10月テスト（181R、1点100円）**

**結論（正直に）**
- **回収率100%を安定して超える買い方は見つからなかった。** 100%を超えたのは2つだけ（モデル1点 119.6%、期待値ルール 110%）。どちらも的中は数本〜12本で、90%区間は100%をまたいでいる。偶然の範囲で、勝てる根拠にはならない。
- 合成モデルの確率は市場確率とほぼ同じ。そのため期待値（確率×オッズ）は控除率の分だけ1を下回り（約0.75）、**期待値1以上の目はほとんど出ない**。
- **1番人気の3連単を買い続けると回収率は約40%** で、人気サイドほど割に合わない。期待値ルールも、人気寄りにすると60〜70%止まり。
- オッズを艇モデルの特徴量に入れると、モデルが市場の後追いになり、かえって悪くなった。
- 判断は5分前オッズで、払戻は最終オッズ。締切直前にオッズが動くことによる差は再現しきれていない。オッズ取得が遅れると、この評価よりさらに不利になる。
- 期間が3か月（576R）と短い。3連単はもともと的中が少ないので、本当に勝てるかを判断するには少なくとも数千レース必要。

**実戦での使い方（試すなら少額で）**
1. 入力：そのレースの出走表（級別・勝率・モーター/ボート2連率・平均ST・コース別成績）、直前情報（展示タイム・展示ST・周回/周り足/直線・展示進入・風/波）、締切5分前の3連単オッズ。kyoteibiyori の `request_race_shusso_detail_v4` / `request_chokuzen_info_v2` / `request_odds_shousai` と同じ中身。
2. `build_dataset.rows_for_race()` で特徴量を作る → 学習済みの艇モデルで1着確率 → `ev_model.harville()` → `bets_for()` で買い目を出す。
3. 期待値ルールの閾値は、データを足すたびに **過去だけで** 選び直すこと。テスト期間で選んではいけない。
