# 周回などの直前情報はオッズに織り込まれているか（2026/08/01〜11/16、5場）

## データ
- kyoteibiyori の直前情報（周回・周り足・直線・展示・展示ST・展示進入）と、締切5分前の3連単オッズ。1リクエストごとに2.5秒あけて取得（取れなかったのは4レースだけ）。
- 結果と配当は公式データ。両方そろった **3,291レース**（桐生628・平和島737・住之江645・丸亀568・大村713）。
- 取得: `venues/kb_scrape_lap_odds.py`、分析: `venues/lap_edge.py`、結果: `venues/lap_edge_result.json`（生データはコミットしていない）。

## 方法
- 市場の見立て = 5分前オッズの 1/オッズ を合計1にしたもの。
- 1着 → 2着 → 3着 の3段階で「市場の条件付き確率の対数 ＋ 直前情報」のモデルを作り、日付で5分割して、学習に使っていない日で比べる。
  - **補正だけ**: 市場の対数確率に係数を掛けるだけ（人気・穴の偏りの補正）。
  - **補正＋直前情報**: 周回・周り足・直線・展示（レース内の偏差）、周回1位とその差、展示ST、展示進入の変化。
- 買う実験: モデル確率 × 5分前オッズ（期待値）が閾値以上の目を100円ずつ。確定配当で精算（確定オッズは5分前より中央値で0.96倍に下がっている。精算ではこの分も含めている）。

## 結果
| 比較（1レースあたりの対数尤度） | 差 | 90%区間 |
|---|---|---|
| 補正だけ − 市場そのまま | +0.011 | +0.007〜+0.015 |
| 補正＋直前情報 − 補正だけ | +0.007 | +0.003〜+0.012 |

- **市場の偏りはある**: 1・2着は人気の艇がオッズより少し多く来て（係数1.14・1.17）、3着は逆に穴の艇がもう少し来る（0.96）。
- **直前情報にも少しだけ織り込み漏れがある**: 周回・直線・展示が速いほど、展示STが早いほど来やすいという、筋の通った向き。場別では丸亀（+0.015）と大村（+0.013）ははっきりしている。桐生・平和島・住之江は0と区別できない。
- 量は小さい。+0.007 は、当たり目の確率をおよそ0.7%押し上げる程度。

| 買い方（6〜50倍の目） | 回収率 | 90%区間 | 点数 |
|---|---|---|---|
| 全部買う（基準） | 75% | 73〜78% | 56,913 |
| 期待値1.0以上 | 86% | 75〜97% | 4,149 |
| 期待値1.1以上 | 84% | 63〜108% | 1,156 |
| 期待値1.2以上 | 113% | 55〜183% | 292 |

- 50倍以上を含めると、どの閾値でも55〜78%に落ちる（大穴は買うほど損）。
- 補正だけのモデルでは、期待値1を超える目がほとんど出ない（104レース・0的中）。上乗せは直前情報の分。
- 途中集計（2,068レース）では「期待値1.1以上・6〜50倍」が99%だったので、全データでこの条件を確かめた。結果は84%に下がった。最初の数字はたまたまの寄りが大きかった。

## 読み方
- 直前情報には「オッズに入りきっていない情報」が少しある。それで、全部買う75%を、狙って買う86%前後まで押し上げられる。
- ただし控除（25%）を超える証拠はない。100%を超えたのは点数の少ない条件だけで、区間は広い。
- 6倍未満の目は期待値の条件でほとんど選ばれないので、この検証では「6倍未満を買わない」の良し悪しは分からない。はっきりしたのは、高すぎる目（50倍以上）を避けた方がよいこと。

## README の C に入れる候補（提案）
- 丸亀・大村では、周回・直線・展示STの上位を、オッズより少し上に見てよい（他の3場では効果がはっきりしない）。
- 買い目の上限オッズを50倍程度にする案。1年分の検証でも「除外ラインを上げるほど回収率が下がる」と出ていて、方向が合う。
- 実戦で試すなら、5分前オッズを見て「6〜50倍・モデル期待値1.0以上」の目だけを記録し、紙上で回収率を数えてから判断する（2,000〜3,000点ほど溜まるまで）。
