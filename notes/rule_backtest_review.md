# 今の買い方ルールの1年分検証（公式データ 5場）

- 対象: 桐生・平和島・住之江・丸亀・大村、2025/11/01〜2026/11/16、**11,779レース**（モデル学習 〜2026/07 の8,457R、検証 2026/08〜 の3,322R）。
- コード: `venues/rule_backtest.py`、結果: `venues/rule_backtest_result.json`。データ取得 `venues/download.py`、変換 `venues/parse.py`（生データはコミットしない）。

## 再現のしかた（近似があるので注意）
- README の分類を機械的なルールにした。
  - 固い: 1号艇が展示1位で2位と0.05秒以上差、風5m未満、A1、50歳未満、枠なり。平和島・桐生1〜5Rは対象外。1-(2・3・4)-(2・3・4) から4点。
  - 荒れそう: 「1号艇B級／モーター2連率30%未満／風7m以上／場の荒れるR番号／B級の展示1位がいる」のうち2つ以上。穴の艇＋強い艇の2軸、3連単6点。
  - 中間: 1号艇がA級なら 1-(2・3・展示上位)-(…5・6含む) の6点、そうでなければ 1号艇と強い艇の裏表6点。
- **周回は公式データに無いので展示タイムで代用**。枠なりは本番の進入で判定。
- **オッズも公式データに無い**。艇の強さのモデル（1着率）から3連単の確率を出し、推定オッズ = 0.75 / 確率 とした。当たり目は実際の配当で精算。推定オッズと実配当の相関（対数）は 0.82。
- 実戦の分類は人の判断なので、ここでの「荒れそう」（全体の50%）は実戦（2〜3割）より広い。

## 結果（1レース800円、全期間／検証期間）
| 買い方 | 的中率 | 回収率 | 回収率90%区間 | 検証期間の回収率 |
|---|---|---|---|---|
| **今のルール（8倍未満除外・高い2点に200円）** | 17.8% | **74%** | 69〜79% | 75%（64〜86%） |
| 除外ラインを6倍に下げる | 21.4% | 76% | 71〜81% | 78% |
| 除外ラインを15倍に上げる | 10.2% | 70% | 65〜76% | 71% |
| 200円をやめて均等買い | 17.8% | 73% | 69〜77% | 72% |
| 中間の2着候補を2・3・4に固定 | 18.0% | 74% | 68〜79% | 76% |
| 比較: モデル上位6点（除外なし） | 35.6% | 78% | 75〜80% | 77% |

分類ごと（今のルール）: 固い 159R 回収82%（57〜108%）、荒れそう 5,853R 72%、中間 5,767R 76%。
場ごと（今のルール）: 大村 80%、住之江 75%、桐生 75%、丸亀 74%、**平和島 66%**。

## わかったこと
- **どの形も回収率は 70〜78%**。控除率25%（何も考えずに買った平均75%）とほぼ同じで、90%区間はすべて100%未満。今のルールを機械的に続けても、長くやれば75%前後に落ち着く見込み。実戦の139レース（60%）はこの範囲の下側で、運の悪さで説明できる幅。
- 除外ラインは**高くするほど回収率が下がる**（6倍 76% → 8倍 74% → 15倍 70%）。README のオッズ帯の表（低いオッズほど回収率が高い）と同じ向き。
- 高い2点に200円は均等買いより +1.4ポイントだけ。差は誤差の範囲。
- 2着候補の選び方（展示上位を入れる／2・3・4固定）では差が出ない。
- 平和島は5場で一番低い（66%）。1号艇が弱く、荒れても配当で取り返せていない。
- 固いは数が少なく（1年で159R）、区間が広すぎて判断できない。

## README の C に入れる候補（提案）
- 「買い目の工夫で控除率（25%）を超える」根拠は、この1年分では見つからなかった。続けるなら、目標を「回収率を上げる」から「負けを小さくして記録を取る」に切り替える案（例: 1レース800円 → 400円、平和島は見送り多め）。
- 除外ラインは6倍のまま（8倍まで避けない）方が、データ上はわずかに良い。ユーザーの方針（6倍未満は買わない）は守ったまま、6〜8倍を避ける運用だけ見直す案。
- 本当に勝てる余地を探すなら、ルールの微調整ではなく、オッズに織り込まれていない情報（周回・直前の気配など）が必要。周回は kyoteibiyori に 2026/08 以降しかないので、3か月分で再検証する案（アクセスは控えめに）。
