# 実戦予想の手順とルール（2026/11/10 に全体を見直し）

対象: 平和島(4)・桐生(1)・大村(24)。開催が少ない日は丸亀(15)・住之江(12)も。
データは kyoteibiyori.com から取得（アクセスは1レースあたり数回、間隔を空ける）。

## スクリプト
- `node live/schedule.js YYYYMMDD` … 5場のその日のレース番号・締切・レース名（開催なしは `none`）
- `bash live/pre5_wait.sh <場> <R> <YYYYMMDD> <出力>` … 周回タイムが出るまで60秒おきに最大10回 `pre5.js` を取り直す（予想はこちら）
- `node live/pre5.js <場> <R> <YYYYMMDD> <出力>` … 展示（周回・周り足・直線・展示ST・チルト）・進入・潮・気象・3連単オッズ
- `node live/card.js <場> <R> <YYYYMMDD> <出力>` → `python3 -I live/card_sum.py <出力>` … 出走表の要約（級別・勝率・当地・直近1か月・SG/G1・得点率・平均ST・モーター2連・事故率・選手の色）
- `python3 -I live/odds3t.py <pre5の出力> 1-2-3 ...` … 3連単オッズ
- `node live/res_day.js <場> <YYYYMMDD> x` … 確定済みの結果

## 毎日の流れ
1. 朝（9:41頃）に `schedule.js` で5場の開催を確認。平和島・桐生・大村が少ない日は丸亀・住之江も予想する。
2. 各レースの締切8分前に予想（send_later で予約、常に次の約10レース分だけ予約するローリング。`live_state_YYYYMMDD.txt` に記録）。
3. **周回タイムを見てから判断する**（ユーザーの指示）。桐生は展示より周回の発表が数分遅く、強風の日は締切が延びる。締切直前まで待ち、出ない時はその旨を伝えて展示タイムで代用。
4. 予想のたびに前のレースを答え合わせ。最終レース後に `notes/<場>_YYYYMMDD_live_review.md` を作ってコミット・push。

## これまでの成績（11/03〜11/09、144レース）
- 投資 108,200円、払戻 92,740円、**回収率 86%（−15,460円）**。プラスの日は 200円を置いた高配当が1本当たった日（11/05・11/07）。
- 3連単は払戻が売上の75%。**何も工夫しないと回収率75%前後**になる。1年分のデータで試した機械的なルールは、どれも70〜90%で、100%を超えたものは無い。
- 144レースでは、うまいか運かは区別できない（高配当1本で±1万円動く）。

## 買い方の基本（ユーザーの方針）
- 1レース6点まで、合計800円。
- 配当6倍未満の目は買わない。締切前6〜8倍も最終で下がるので避ける。
- オッズの高い目に厚く（6点なら上位2点200円・他100円）。
- レースを「固い／荒れそう／中間」に分け、予想に分類を書く。
  - **固い → 2〜3点**。条件: 1号艇の周回が2位より0.3秒以上速い、または1号艇がA1で今節得点率トップ。かつ風5m未満、かつ場のインが強い時間帯。**条件を満たす時だけ**。買い目は 1-X-(2〜3艇)。
  - **荒れそう → 穴**。条件（2つ以上）: 1号艇がB級で不調／モーター不調、風7m以上、場の荒れやすいレース番号・企画、穴の要素の艇がいる。買い目は2軸（穴の艇＋力のある艇）の3連複4点＋3連単2点。
  - **中間 → 6点**。1号艇1着固定なら 1-(3艇)-(3艇)、絞れなければ2艇の裏表。

### ⚠ 方針とデータが食い違っている点（2026/11/10 の見直しで判明。変えるかはユーザーが決める）
3連単を締切5分前のオッズ帯ごとに全部買った時の回収率（桐生・大村・平和島 2026/08〜10、約1,780レース、払戻は確定値）:

| 5分前オッズ | 〜6倍 | 6〜8 | 8〜12 | 12〜20 | 20〜30 | 30〜50 | 50〜100 | 100倍〜 |
|---|---|---|---|---|---|---|---|---|
| 回収率 | **101%** | **88%** | 77% | 66% | 75% | 79% | 71% | **56%** |
| 的中率 | 21.8% | 13.3% | 8.4% | 4.5% | 3.2% | 2.1% | 1.0% | 0.2% |

- **一番回収率が高いのは、買わないことにしている「8倍未満」の目**。一番低いのは100倍以上。
- 「6倍未満は買わない」「高い目に厚く」は、当たっても損（トリガミ）を避けるための決めごとだが、回収率だけ見ると逆向き。
- 〜6倍は316件と少ないので、101%は偶然の幅が大きい。ただ「低いオッズほど回収率が高い」向きは3場とも同じ。
- 100倍以上の目（万舟狙い）は回収率56%。万舟を狙うなら30〜100倍の帯まで。

## 判断の順番（1レースごと）
1. **周回タイム**: 1位は誰か、2位との差は0.3秒以上か。場内だけで比べる（桐生は半周18秒台、他は36〜38秒台）。
2. **1号艇を信用できるか**: 級別／周回順位／`選手の色` のイン得意・苦手／年齢／モーター／企画レースの種別／場とレース番号。
3. **相手を選ぶ**: 2連単の人気上位と、足（周回・展示）上位の両方から。穴の要素の艇、今節の得点率、選手の色（5・6コース3着得意、前付け、外に出る）。
4. **水面と進入**: 風・波、潮（平和島・大村）、展示の進入（前付け）。
5. **分類して買い目を決める**。オッズを確認する。

## やらないこと
- 周回が遅いだけ、STが遅いだけ、コメントが悪いだけ、事故率・賞除だけで、艇を2・3着から外さない（11/03〜06 に何度も裏目）。
- 1日だけの偏りをルールにしない。新しい気づきは C に書き、1年分のデータで確かめてから A・B に上げる。
- 大村の予想に平和島の傾向を使わない（場ごとに分ける）。
- 自信の%は目安。分類ごとの的中率を記録して合わせていく。
