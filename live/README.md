## スクリプト
- `node live/schedule.js YYYYMMDD` … 5場のその日のレース番号・締切・レース名（開催なしは `none`）
- `bash live/pre5_wait.sh <場> <R> <YYYYMMDD> <出力>` … 周回タイムが出るまで60秒おきに最大6回 `pre5.js` を取り直す（予想はこちら）
- `node live/pre5.js <場> <R> <YYYYMMDD> <出力>` … 展示（周回・周り足・直線・展示ST・チルト）・進入・潮・気象・3連単オッズ。**展示の表の列は進入順**。`===進入順の枠番`（枠なりかどうか）と `===欠場の疑い` の行も出す（11/22 追加）
- `node live/card.js <場> <R> <YYYYMMDD> <出力>` → `python3 -I live/card_sum.py <出力>` … 出走表の要約（級別・勝率・当地・直近1か月・SG/G1・得点率・平均ST・モーター2連・事故率・選手の色）
- `python3 -I live/odds3t.py <pre5の出力> 1-2-3 ...` … 3連単オッズ
- `node live/res_day.js <場> <YYYYMMDD> x` … 確定済みの結果
- `python3 -I live/day_summary.py YYYYMMDD [...]` … 記録（notes/picks）から、場ごと・レースごとの表と場ごとの合計を出す。**ユーザーへの成績の報告はこの形**（11/24 ユーザー指示）。日付を複数渡すと期間の場ごとの合計

## 買い方の基本（ユーザーの方針、2026/11/17 に決定）
- **1レース600円まで**（6点まで、1点100円が基本）。
- **6倍未満は買わない**。**6〜8倍を買う時は2点まで**。
- **「荒れる」の定義（11/18 決定）: 荒れた = 3連単10,000円以上（万舟）**。荒れそう = 万舟になりそうなレース → **万舟の目（締切前100倍以上）を狙う**。安い順に寄せ、総流しはしない。中穴（20〜100倍）は中間で使う。詳しくは `notes/manshu_review.md`。
- オッズの高い目に厚く（600円の中で、穴の目に200円を置いてよい）。
- **このルールで少なくとも2節は変えずに続ける**（2026/11/18〜）。日々の反省は振り返りの「提案」に書くだけにして、途中でルールを変えない。2節終わったら親セッションで判定する。
- 予想には**節の何日目か**（初日・2日目・中日・準優日・最終日）を書き、記録にも残す。`notes/setsu_day_review.md` の日ごとの傾向を使う。
- レースを「固い／荒れそう／中間」に分け、予想に分類を書く。
  - **固い → 2〜4点**。条件は全部満たすこと: ①1号艇が周回1位で2位に0.3秒以上の差 ②風5m未満 ③1号艇がA1（またはイン得意）④イン苦手・50歳以上・B2 でない ⑤枠なり ⑥平和島と桐生1〜5Rは対象外。2着に2号艇を必ず入れ、3着は2〜6号艇から。6〜8倍は2点まで。
  - **荒れそう（万舟になりそう）→ 締切前100倍以上の目を6点まで**（11/22 に場ごとの基準へ変更、ユーザー決定。`notes/venue_are_review.md`）。荒れ要素を数える: ①1号艇B級 ②1号艇の展示タイム5〜6位 ③風5m以上 ④1号艇モーター2連率30%未満 ⑤節の初日 ⑥B級の展示1位（2〜6号艇）がいる ⑦枠なりでない。場の万舟が多いR（桐生1〜5R、住之江3R、平和島10・12R、丸亀1・2・9R、大村2R）と平和島の最終日は1つ足す。
    - **場ごとの違い**: **桐生は⑥を数えない**（桐生では逆向き）。**平和島は⑦を数えない**（平和島では逆向き）。**大村は5つ以上で荒れそう**（4つでは万舟率16%で平均並み、5つ以上で38%）。他の場は4つ以上。
    - **1場1日3本まで**: その日その場ですでに3本を荒れそうにしていたら、それ以降は基準より1つ多い時だけ荒れそうにする（強風の日に荒れそうが固まるのを防ぐ）。
    - 記録には、この数（今の要素数）と並べて**「場ごとの要素数」**も書く。場ごとの要素: 桐生＝1号艇B級・風5m以上・風7m以上・波5cm以上・1〜5R／平和島＝1号艇の展示5〜6位・風5m以上・風7m以上／住之江＝1号艇の展示5〜6位・初日・枠なりでない・A1が0人／丸亀＝1号艇B級・風5m以上・風7m以上・波5cm以上・初日・枠なりでない／大村＝1号艇モーター30%未満・1号艇の展示5〜6位。2節分で、どちらが万舟を当てるか比べる。
    - 展示の表は**進入順**（前付けがあると枠番順でない）。`pre5.js` の `===進入順の枠番` と `===欠場の疑い` の行で確認してから②⑥⑦を数える。
    - 1号艇は弱い理由だけで外さない（1号艇2・3着の万舟目も入れる）。荒れそうでも万舟は4〜5回に1回なので、的中率は低い前提。
  - **中間 → 6点**。1号艇1着固定なら 1-(2・3・4)-(2〜6)。6〜8倍は2点まで、残りは10〜50倍（中穴）から。

### 方針とデータの関係（2026/11/10 の見直し。**ユーザーの判断: 方針は変えない。6倍未満は買わない、買うなら高いオッズを生かす**）
3連単を締切5分前のオッズ帯ごとに全部買った時の回収率（桐生・大村・平和島 2026/08〜10、約1,780レース、払戻は確定値）:

| 5分前オッズ | 〜6倍 | 6〜8 | 8〜12 | 12〜20 | 20〜30 | 30〜50 | 50〜100 | 100倍〜 |
|---|---|---|---|---|---|---|---|---|
| 回収率 | **101%** | **88%** | 77% | 66% | 75% | 79% | 71% | **56%** |
| 的中率 | 21.8% | 13.3% | 8.4% | 4.5% | 3.2% | 2.1% | 1.0% | 0.2% |

- **一番回収率が高いのは、買わないことにしている「8倍未満」の目**。一番低いのは100倍以上。
- 「6倍未満は買わない」「高い目に厚く」は、当たっても損（トリガミ）を避けるための決めごとだが、回収率だけ見ると逆向き。
- 〜6倍は316件と少ないので、101%は偶然の幅が大きい。ただ「低いオッズほど回収率が高い」向きは3場とも同じ。
- 100倍以上の目（万舟狙い）は回収率56%。万舟を狙うなら30〜100倍の帯まで。

## 判断の順番（1レースごと）
1. **周回タイム**: 1位は誰か、2位との差は0.3秒以上か。場内だけで比べる（桐生は半周18秒台、他は36〜38秒台）。
2. **1号艇を信用できるか**: 級別／周回順位／`選手の色` のイン得意・苦手／年齢／モーター／企画レースの種別／場とレース番号。
3. **相手を選ぶ**: 2連単の人気上位と、足（周回・展示）上位の両方から。穴の要素の艇、今節の得点率、選手の色（5・6コース3着得意、前付け、外に出る）。
4. **水面と進入**: 風・波、潮（平和島・大村）、展示の進入（前付け）。
5. **分類して買い目を決める**。オッズを確認する。
