# 実戦予想の手順（平和島・桐生・大村、レースがある日は毎日）

対象: 平和島(4)・桐生(1)・大村(24)。kyoteibiyori.com から取得（アクセスは1レースあたり数回、間隔を空ける）。

## スクリプト
- `node live/schedule.js YYYYMMDD` … 3場のその日のレース番号・締切・レース名を表示（開催なしは `none`）
- `node live/pre5.js <場> <R> <YYYYMMDD> <出力>` … 展示（周回・周り足・直線・展示ST・体重・コメント）・気象・3連単オッズ・単勝
- `node live/card.js <場> <R> <YYYYMMDD> <出力>` → `python3 -I live/card_sum.py <出力>` … 出走表の要約（級別・勝率・当地・直近1か月・SG/G1・得点率・今節平均ST）
- `node live/res_day.js <場> <YYYYMMDD> x` … 1Rから確定済みの結果（着順・3連単払戻・人気・決まり手）

## 毎日の流れ
1. 朝（9:41頃）に `schedule.js` で3場の開催とレースを確認。開催がなければその旨を伝えて終了。
2. 各レースの **締切8分前** に予想を出す（send_later で予約）。予約は作成数に上限があるので、**常に「次の約10レース分」だけ予約**し、予想を出すたびに足りない分を追加する（ローリング）。予約済みの一覧は scratchpad の `live_state_YYYYMMDD.txt` に記録。
3. 予想を出すたびに、前のレースの結果も確認して答え合わせ。
4. 最終レースの後、3場の結果一覧・収支・振り返りを `notes/<場>_YYYYMMDD_live_review.md` にまとめてコミット・push。

## 予想ルール（2026/11/03 の反省を反映）
- 1レース6点まで。
- **配当6倍未満の目は買わない**（当たっても損になる）。
- 掛け金は **オッズの高い目に厚く**（ユーザーの方針）。標準: 6点のうちオッズ上位2点は200円、残りは100円（合計800円）。
- 足の比較は **周回タイム最優先**。ただし **周回タイムが遅いだけで2・3着から外さない**。
- スタートは展示STではなく **今節の平均ST** を見る。
- **級別より今節の調子（得点率・平均ST）** を重く見る。
- 1号艇が **グレード常連（SG/G1経験）** かを確認。
- 場ごとの傾向:
  - 大村: イン61%、7R以降約7割。**1号艇1着固定の時は2着に2号艇と3号艇を必ず入れる**（逃げた時の2着は2コース36.9%で最多、11/04は2着の半分が3号艇）。平和島の傾向は使わない。
  - 桐生: 1〜5R は荒れる。風6m/波6cm以上でイン約4割。B1でも今節好調なら信用。展示データは出ている（コメント欄が無いだけ）。桐生の周回タイムは半周計測で18秒台（他場と単位が違うので場内で比較する）。
  - 平和島: イン45%と弱い。3号艇・5号艇も1着候補。6号艇は3着候補に必ず入れる。3R・7Rが荒れやすい。
- 1着を絞れないレースは、1・2着を2艇で決め打ち（XY-XY-3艇）か見送り。
- 1号艇1着固定の時は、2着候補を3艇にした「1-(3艇)-(3艇)」を基本にする。2着候補は2連単の人気上位と足（周回・展示）上位の両方から選ぶ。
- 今節のSTが遅いだけ、コメントが悪いだけ、周回が遅いだけでは艇を外さない（11/03〜04 で何度も裏目）。
- 勝負レース候補（記録用）: 桐生・一般戦・1号艇A1・2〜6号艇が全員B級 → 2連複 1=（残りで全国勝率1位）を記録。
