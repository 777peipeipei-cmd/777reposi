# 実戦予想の手順（平和島・桐生・大村、レースがある日は毎日。開催が少ない日は丸亀も）

対象: 平和島(4)・桐生(1)・大村(24)。開催が少ない日は丸亀(15)も（`node live/schedule.js YYYYMMDD 15`）。kyoteibiyori.com から取得（アクセスは1レースあたり数回、間隔を空ける）。

## スクリプト
- `node live/schedule.js YYYYMMDD` … 3場のその日のレース番号・締切・レース名を表示（開催なしは `none`）
- `bash live/pre5_wait.sh <場> <R> <YYYYMMDD> <出力>` … 周回タイムが出るまで60秒おきに最大10回 `pre5.js` を取り直す（予想はこちらを使う）
- `node live/pre5.js <場> <R> <YYYYMMDD> <出力>` … 展示（周回・周り足・直線・展示ST・体重・コメント）・気象・3連単オッズ・単勝
- `node live/card.js <場> <R> <YYYYMMDD> <出力>` → `python3 -I live/card_sum.py <出力>` … 出走表の要約（級別・勝率・当地・直近1か月・SG/G1・得点率・今節平均ST）
- `node live/res_day.js <場> <YYYYMMDD> x` … 1Rから確定済みの結果（着順・3連単払戻・人気・決まり手）

## 毎日の流れ
1. 朝（9:41頃）に `schedule.js` で3場の開催とレースを確認。開催がなければその旨を伝えて終了。
2. 各レースの **締切8分前** に予想を出す（send_later で予約）。予約は作成数に上限があるので、**常に「次の約10レース分」だけ予約**し、予想を出すたびに足りない分を追加する（ローリング）。予約済みの一覧は scratchpad の `live_state_YYYYMMDD.txt` に記録。
3. 予想を出すたびに、前のレースの結果も確認して答え合わせ。
4. 最終レースの後、3場の結果一覧・収支・振り返りを `notes/<場>_YYYYMMDD_live_review.md` にまとめてコミット・push。

## 予想ルール（2026/11/03 の反省を反映）
- **周回タイムを見てから判断する**（ユーザーの指示）。`pre5_wait.sh` で周回が出るまで待つ。**桐生は展示タイムより周回の発表が数分遅い**（11/07: 展示だけ先に出て周回は「-」、後から出た）。強風の日は締切が延びることもある（11/07 2R 15:45→15:51）ので、締切直前まで待つ。それでも出ない時は、その旨を伝え、展示タイムで代用する。
- 1レース6点まで。
- **配当6倍未満の目は買わない**（当たっても損になる）。締切前の6〜7倍は最終で6倍を切ることがあるので避ける。
- 掛け金は **オッズの高い目に厚く**（ユーザーの方針）。標準: 6点のうちオッズ上位2点は200円、残りは100円（合計800円）。
- 足の比較は **周回タイム最優先**。ただし **周回タイムが遅いだけで2・3着から外さない**。
- スタートは展示STではなく **今節の平均ST** を見る。
- **級別より今節の調子（得点率・平均ST）** を重く見る。
- 1号艇が **グレード常連（SG/G1経験）** かを確認。
- **穴の要素**（`notes/hole_factors_review.md`）: **B級でも「展示タイム1位（2位との差が大きいほど良い）・今節好調・モーター好調」が重なる艇は、3着内が平均より10〜17ポイント高いのに人気になりにくい**。1コースならB級でも1着候補（展示1位で単勝回収98〜105%）、2〜4コースなら2・3着に必ず入れる。6コースは効果が小さい。逆にB級で展示最下位・今節不調は3着内−8ポイント。
- **勝負駆け・F持ち**（`notes/shobu_review.md`）: 出走表の `順位` が「賞除」（節でF等）の選手は **STを約0.035秒控える**ので、平均STの遅さで評価を下げすぎない（着順はほぼ平均どおり）。ただし外枠からのまくりは期待しにくい。**賞除でも2・3着には来る**（11/06 丸亀7R）。予選最終日の上位6位（安全圏）は2回乗りの1走目でも普通に強く、「流す」傾向はデータでは見えない。勝負駆け（19〜24位付近）はFがやや多い程度。
- **事故率・期末**（`notes/kimatsu_jiko_review.md`、`card_sum.py` の `事故率`）: **事故率0.50以上の選手はSTを控え、3着内が4〜5ポイント低い**（0.70以上はさらに控える、期末は特に）→ 1着候補としては評価を下げるが、**2・3着候補からは外さない**（11/06 桐生6R、事故率0.52の艇が3着）。期末（4月・10月）に勝率が級別の境界の少し下（昇格を狙える）の選手は1着が約1ポイント上がる程度で、差は小さい。
- **モーター2連率**（`card_sum.py` の `モーター2連`、`notes/motor_boat_review.md`）: 45%以上は3着内+4ポイント・1着+2.6、30%以下は3着内−2ポイント。**A2・B1の1号艇はモーター40%以上でイン1着が6〜8ポイント上がる**（A1は差が小さい）。ボート2連率はほぼ効かないので使わない。
- 選手の要素（`notes/racer_factors_review.md`、級別ごとに比較）: **50歳以上の1号艇はイン1着が約10ポイント低い**（A1 62%、B1 31%）。**B1の地元選手の1号艇は約4ポイント高い**（A1は差なし）。性別は同じ級別なら差は小さい。体重は級別・性別と混ざっていて単独では使わない。ナイター適性（過去のナイター成績）は次の成績をほぼ予測しない。ナイター出走が少ない選手（2割以下）がナイター場の1号艇の時だけ、イン1着がやや低い（−5.6ポイント、参考）。
- 場ごとの傾向:
  - 大村: イン61%、7R以降約7割。**1号艇1着固定の時は2着に2号艇と3号艇を必ず入れる**（逃げた時の2着は2コース36.9%で最多、11/04は2着の半分が3号艇）。平和島の傾向は使わない。
  - 桐生: 1〜5R は荒れる。**静水面（風0〜2m）では2コース差しが多い**（11/05 は2号艇1着6回・全部差し、うち4回は2着が1号艇）。2号艇を1着に置く時は2着に1号艇を必ず入れる。**強風（風7m以上）の日はカドの4号艇のまくりが増える**（11/07: 風9mで4号艇1着3回、すべて5,000円以上）。風6m/波6cm以上でイン約4割。B1でも今節好調なら信用。展示データは出ている（コメント欄が無いだけ）。桐生の周回タイムは半周計測で18秒台（他場と単位が違うので場内で比較する）。
  - 丸亀（`notes/marugame_1year_review.md`）: イン55.6%。1号艇A1は72%、B1は42%。**2〜7Rは荒れやすく（イン36〜49%）、8R（釜揚げ８・進入固定）は78%、9〜12Rは61〜73%**。逃げた時の2着は2コース36%・3コース25%・4コース20%、3着は4コースが最多で散らばるので3着は広めに。6コースの3着内25.5%。無風・静水面はインが強い（70%）。潮の影響は小さい（下げ潮は5コースの1着がやや増える）。周回1位の1号艇は63%。
  - 平和島: イン45%と弱い。3号艇・5号艇も1着候補。6号艇は3着候補に必ず入れる。3R・7Rが荒れやすい。
- **潮の満ち引き**（`pre5.js` の `===潮` 行: 干潮・満潮時刻と潮名。締切時刻が上げ潮か下げ潮かを判定する）:
  - 平和島（海水）: 上げ潮は1コース1着44.2%、下げ潮は37.4%・万舟率21.7%（上げ潮16.5%）。**下げ潮のときはインを割り引き、5コースの1着（11.5%）も押さえる**。満潮・干潮の転換前（4.5時間以上経過）は1コース35.1%と低い。

  - 集計は 2026/08〜10 の約600レースずつ（`venues/tide_check.py`）。大村の締切時刻は標準の時刻で近似。差は数ポイントで、偶然の可能性も残る。
